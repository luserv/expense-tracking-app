# Product Context

## Product Name
Segato — Control de Gastos

## Register
product

## Product Purpose
Offline-first personal finance tracker with double-entry bookkeeping (Firefly III logic). Tracks income, expenses, transfers between accounts, recurring bills, savings goals (piggy banks), and budgets by category. Full data ownership — no cloud dependency; SQLite on device.

## Users
Individual users managing personal or household finances. Primary persona: budget-conscious adult (25–45) who wants clear control of money without relying on a bank's app. Uses the app daily to log transactions and weekly to review summaries. Also targets power users who want envelope-style budgeting and recurring bill tracking.

## Platforms
- Android (Expo / React Native)
- Desktop (Electron, wraps the same React Native Web bundle)

## Languages
- Spanish (primary)
- English

## Brand Tone
Calm, trustworthy, precise. Not playful. Not corporate. A well-designed personal tool — like a quality notebook. Confidence through clarity.

## Anti-References
- Mint / Intuit: loud, ad-driven, intrusive
- Banking apps: sterile, impersonal, excessive whitespace
- Generic SaaS dashboards: hero-metric grids, gradient text everywhere
- Neon crypto wallets: aggressive dark with glowing accents

## Strategic Principles
1. Data first — numbers must be instantly readable; decoration never obscures.
2. Offline first — no spinners for data; instant from SQLite.
3. One hand, one thumb — mobile primary; all critical actions reachable without stretch.
4. Earn trust through consistency — same language, same spacing, same interaction model throughout.
